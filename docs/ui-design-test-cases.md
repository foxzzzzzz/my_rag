# UI整体设计：样稿验收用例

日期：2026-11-06。编码前发布；适用Phase 3U设计样稿，不替代真实接口或生产验收。

| 编号 | 操作/场景 | 预期结果 |
|---|---|---|
| U01 | 在资料库、资料详情与审核、问答之间切换 | 导航选中态和页面标题一致；明确标识交互样稿/演示数据 |
| U02 | 资料库搜索、来源类型/审核状态过滤、清空 | 可见结果准确变化；无结果提供恢复入口；没有大量无用途空白 |
| U03 | 从资料进入详情 | 显示所选标题、来源类型与审核状态；HTML不出现语音/画面专属标签 |
| U04 | 阅读视频/HTML正文，切换证据、管理操作 | 正文优先、辅助操作分区；数字/术语、段落、表格与长标题可读；危险操作不与主动作争抢 |
| U05 | 打开待审资料，输入评分/意见；97/98分、改分未保存、切证据和导航返回、保存后批准 | 无评分/低于98分/未保存改动不能批准；草稿返回保留，保存/批准后意见可查，旧草稿不覆盖新保存值；仅演示内存，不写真实库 |
| U06 | 打开已批准资料 | 显示对应状态与已存演示分数，不沿用“待本人核对”；修改后须重新审核的边界可见 |
| U07 | 问答输入、范围、引用①、来源证据 | 首屏可提问；范围简洁；回答有自然段和标题；引用可打开对应证据，技术字段折叠 |
| U08 | 演示问答/无答案，查看高级设置 | 明示为预置回答；无依据时拒答；索引诊断为次级入口；保留真实功能需要付费确认的说明 |
| U09 | 1440px/390px与键盘浏览、切换正文/证据 | 页面无整体横向溢出；小屏导航/阅读/审核可达；按钮有名称、可见焦点、表单有标签；阅读切换保留焦点；有名称的弹层可Esc关闭并返回有效焦点 |
| U10 | 在8765原CSP下运行，点击所有演示动作 | 外部同源JS/CSS加载；不调用业务API/模型，不修改真实数据或评分草稿；不修改现有业务入口 |
| U11 | 评审与交付 | 三页截图和地址、实现与未实现清单齐全；结论明确为待用户确认，不宣称上线或生产验收通过 |

结果记录：[ui-design-validation.md](ui-design-validation.md)。先由代理完成工程与视觉检查，再由本人确认视觉方向、页面布局与操作流程。
