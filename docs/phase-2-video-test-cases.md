# Phase 2B 视频编排、恢复与清理测试用例

日期：2026-11-04；编码前定义，依据PRD v0.10。默认temporary；不创建OSS，不改变模型/检索选型。

| 编号 | 场景 | 验收标准 |
|---|---|---|
| B01 | 完整视频自动链路 | 原件校验→全长WAV→抽帧→临时上传→ASR→逐帧视觉→音画整理→不可变待审版本；原件不变，不自动评分 |
| B02 | 配置/资源/能力不满足 | 缺Key、非法参数、无音轨、空帧、磁盘/内存保护、超长/截断输出显式失败；调用前拒绝，不静默降质 |
| B03 | 阶段缓存 | 内容SHA、模型/参数/提示指纹绑定；完成结果重开可复用，不重复POST；更改方案或篡改缓存拒绝 |
| B04 | 全局预算 | 沿用累计research-budget.sqlite，阶段POST前原子预留；超预算/价格未知拒绝；超时保留预留，恢复不重复预留，usage/估算/失败留痕 |
| B05 | 提交与task_id崩溃窗 | POST前持久in_flight；已得到ID先存再轮询；无ID的未知提交停needs_attention，不冒充幂等提交 |
| B06 | ASR远端恢复 | 明确resume领取新令牌；有task_id仅GET原任务，原生时间戳有效；恢复不重新上传/POST，不要求旧临时URL仍有效 |
| B07 | 轮询与结果下载故障 | 限时轮询，超时待恢复；GET失败可显式恢复，ASR返回成功但结果未下载不能称完整完成 |
| B08 | 视觉/文本不确定状态 | 同步POST未知不自动重发；成功输出缓存、长度/格式检查和用量记录；不自动换模或放宽质量 |
| B09 | 续租与取消 | 长任务周期续租，取消/删除/旧令牌阻止下一次外呼和完成写入；只结束本任务子进程 |
| B10 | 持久对象归属 | 正式对象key在PUT前登记后端/桶/地域/前缀/任务；进程重启仍能核实归属，错误scope/任务不能删 |
| B11 | 清理时机 | 未知远端状态保留；ASR终态且结果已落盘/任务终止可明确清理；任务运行中不启动独立清理 |
| B12 | 清理失败/临时路径 | 正式delete失败可再次清理且不伪成功；临时路径仅标provider_managed/48h，不称主动删除；不保存签名URL到日志/公开状态 |
| B13 | 长期产物/短期音频 | 关键帧、证据、摘要/笔记保留；仅清理已登记的本次WAV或远端音频，不删原件/其他任务目录；7天原片清理仍后续单列 |
| B14 | CLI与兼容 | 新增显式video-run/video-resume/video-cleanup/video-status；原2A命令不自动变成付费操作，错误JSON脱敏、历史数据库可用 |
| B15 | 合并验收 | 离线fake验证只能称功能通过；一条现有真实视频新链路成功且待审核，费用可追溯；正式OSS实联调和目标机完整资源未测即标未测 |

远端同步接口无法查询的未知POST不承诺自动恢复。已有task_id才可ASR查询恢复。真实模型输出仍需本人评分；本轮不继承旧分数。
