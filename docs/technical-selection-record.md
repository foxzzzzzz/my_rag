## 1. 当前结论

最新工程状态：Phase 2D及Phase 3本机工程已通过，详见[正式RAG验收](phase-3-rag-validation.md)。下述旧“尚未实现/未验证”文字为选型时历史状态；Obsidian往返、Cookie链接当前授权作品下载及正式RAG已分别有后续证据。当前仍待本人审核业务新版本、正式问答真实反馈和Phase 4目标环境验收。

正式检索在范围内精确计算余弦距离：固定sqlite-vec0.1.9，普通chunks表同步保存float32 blob，使用sqlite-vec C函数，vec0保留同事务一致性。原因是该版本范围KNN边界及逐行读取虚表embedding实测问题；不采用全局TopK后过滤。FTS也在allowed表内排名，双路Top10/RRF60。当前1万块配置上限，不宣称ANN或百万规模能力；新schema及空间变更需显式重建。未引入额外数据库/Key或重排模型。

建议保留现有已获本人认可的模型组合，以及**标题分块＋FTS5/向量混合检索＋单任务媒体处理**。目标机索引和离线媒体资源均已实测。业务已采用轻量FastAPI/React/SQLite单worker架构，不引入图数据库、独立向量服务或分布式队列。

C01/C02不变；2A/2B后端及2C1网页已实现，本机浏览器验收见[网页验证](phase-2-web-validation.md)。真实V01仍待本人，未新增模型调用；2C2a/b工程结果见[内容验收](phase-2-content-validation.md)，两份HTML新版本待本人；2C2c/d及2C2e离线工程见[管理验收](phase-2-management-validation.md)，后续D05/2D和正式云端整体验收，不把本机通过扩展为生产上线。

## 4. 参数与实现约束

| 参数组 | 已测配置 | 生产实现要求 |
|---|---|---|
| 音频 | 16kHz、单声道PCM WAV，时长容差1.5秒 | 保留原片与原生句时间，禁止截断后标全片 |
| 图片 | 最大宽2560且不放大、JPEG质量2 | 原图/时间证据落盘，不将全视频帧存内存 |
| 抽帧 | V01=21、V02=22、V03=16，时间覆盖＋场景候选 | `config/demo-run.json`记录实际参数；长密集文字视频尚未验证，不能把短片帧上限等同质量保证 |
| 普通问答 | Top10召回、前5块、JSON回答＋引用ID＋证据不足标志 | 合法引用还需支持结论；结果页只列实际引用；诊断排名另存 |
| 输出长度 | 视频整理8192；长HTML受控16384；普通回答2048，场景复评4096 token | 是已测配置，不是所有输入均适用的统一上限；长度失败显式停止并留记录，不截断、不无限重试 |
| 资源 | 单worker、3,000,000,000字节整机占用代理上限、最小可用内存512MiB、可用磁盘8GiB保护线 | 将研究保护迁入业务任务机制并实测；不得误称生产停收/队列已经实现 |

所有参数外置并解释。已有`config/demo-*.json`、`config/retrieval-*.json`、`config/media-resource.json`为实验快照，**不能直接当成生产配置或API契约**。新生产配置应区分模型能力、处理策略、资源、保留周期和部署地址。

## 5. 候选、备用及不选内容

- `qwen3.7-text-embedding-flash`是已完成向量/排名初筛的候选，未按它生成整套问答，也未完成该空间的目标机索引回归，因此不冻结为可自动切换的备模型。若采用，独立重建索引、复评与性能回归。
- ASR/视觉其他候选只有文档调研，不宣称已获得可用质量备用。主服务故障时保留任务/缓存、查询已提交task，或由本人处理；不默认双路、静默改供应商或盲目重复POST。
- 抖音链接受限时保留已确认的本地上传兜底；没有验证生产Cookie下载，不做自动登录或收藏同步。
- 暂不引入重排模型、图数据库、Redis/Celery、独立向量数据库；需要时以真实问题证明收益后再增，不以候选名代替实测。
