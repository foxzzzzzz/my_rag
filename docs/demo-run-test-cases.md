# 完整Demo实施前用例

日期2026-11-04。只转换sources现有3视频+2HTML供本人评分，不进入RAG。

| 编号 | 用例 | 预期 |
|---|---|---|
| D01 | 五份清单、源文件与配置哈希 | 来源可追踪，配置/素材变化不复用旧运行结果 |
| D02 | 全视频音频提取及ASR | 覆盖真实全长，原生句时间，保留原输出；不以5秒探测冒充全片 |
| D03 | 混合抽帧 | 短密集片段时间密采样、长屏幕场景变化+覆盖、口播全程覆盖；记录每帧时间与实际数量，标明抽样非逐帧识别 |
| D04 | HTML静态转换 | 不执行脚本/联网；保留标题、代码、表格、SVG原件及结构上下文，正文不截断 |
| D05 | 每模型调用 | 原子预算预留、阶段缓存、异步task恢复、未知费用保守占用；总额≤20且累计≤100 |
| D06 | 付费请求出错/中断 | 不默默重复提交，不伪造输出；报明确未完成阶段并保留成功结果 |
| D07 | 文本合成 | 非空摘要和Markdown笔记；只据材料，标明冲突/模糊；JSON正确、无截断，原始证据另存 |
| D08 | 评审产物 | 五份bundle校验通过，标题和原件可定位、摘录/笔记可读，待评分不预填分数 |
| D09 | 缓存再次执行 | 已成功stage不再次付费；源/参数版本变更必须新版本及重评 |
| D10 | 展示与脱敏 | 原材料不作为脚本执行；HTML/模型输出转义；Key/临时签名URL不入日志/报告 |

先假传输/本地提取验收，再真实运行，实际质量由本人评分。每阶段记录usage估价及保守预留，均不冒充官方账单。
