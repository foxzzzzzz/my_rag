## 决策记录

- 历史版本按最新审核判断。存在达标批准旧版时，批准和其他旧版的名额独立。达标批准旧版超额或其他旧版不足时，剩余名额不互补。没有达标批准旧版时，两个配额合并用于其他旧版。
- 沿用已确认的灰蓝界面、正文阅读宽度和评分草稿、显式提交的交互边界。

## 回归范围

- 后端验证历史清理和恢复、Web API、导入、登录及抖音下载。数据位于隔离库，费用与媒体请求使用测试替身。
- 前端运行单测、Vite 构建及 [Edge 验收脚本](../tools/check_ui_consistency.py)，补验模拟延迟网络和问答费用边界。验证使用 320px、390px、768px、861px 及桌面视口。
- 生产状态待发布。历史版本处理只对之后启用的维护流程生效，已清理内容的恢复需要对应冷备。既有上传记录沿用原来的名称。
