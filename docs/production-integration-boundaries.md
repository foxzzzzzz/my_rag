## 1. ASR：模型已验证，正式音频传输尚未验证

已测：百炼北京paraformer-v2 REST异步提交、task_id查询、结果下载及原生句时间；demo通过官方临时上传，带临时资源解析头。官方临时URL有效48小时，明确要求不要用于生产。该限制未因单用户、小流量或质量评分通过而消失。[官方临时上传限制](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)

**后续手动启用路线：独立私有OSS Bucket＋专用音频前缀＋限时签名HTTPS GET URL。** 由服务器将提取音频上传，给ASR服务文件URL，沿用已测REST异步识别。北京地域为建议，具体Bucket/Endpoint和账号授权尚未配置。若用户已有COS/S3兼容存储，可先记录类型/地域再验证下载兼容性，不直接当作已通过。

Paraformer接受HTTP/HTTPS文件URL；OSS支持为私有对象签名下载URL。这构成技术上可行的接入建议，**不是本项目已完成联调的证据**。[Paraformer API](https://help.aliyun.com/zh/model-studio/paraformer-recorded-speech-recognition-restful-api)、[OSS签名下载](https://help.aliyun.com/zh/oss/developer-reference/python-download-using-a-presigned-url)

建议配置/权限：

- 模型仍使用既有百炼Key；存储另需专用授权，优先支持受限RAM角色/STS，部署环境不支持角色时使用仅限本Bucket/前缀的专用RAM凭证，不使用主账号全权限密钥。
- 仅授予本音频前缀所需写入/读取/清理权限；默认私有，不开启公共读，不借用网站/小程序Bucket权限。
- 记录Bucket、Region、Endpoint、Prefix、凭证引用、签名有效期和清理策略；密钥只在服务器私密配置，不能发到聊天、写前端或Markdown。
- 签名URL本身具有临时访问能力，日志/导出须脱敏。URL使用可被ASR服务访问的HTTPS地址，不假设服务器内网域名、localhost或网页登录Cookie可用。
- 有效期需覆盖真实排队及下载窗口，并受STS凭证剩余寿命约束；不把示例固定时长写成保证。已提交task状态未知时先查询，不能直接续签后再POST制造重复付费任务。
- 正常情况下结果持久化且远端任务终态明确后清理临时对象。对象生命周期兜底建议24小时，正式值须结合签名/排队联调确认；这是保留策略目标，不承诺存储服务异步生命周期恰在24小时删除，实际清理须核对。本地原片7天、长期笔记/证据保留规则独立。上传对象只用于ASR，不把整个知识库迁移到OSS。

当前`temporary`为默认模式，`managed_oss`仅显式启用；配置见[ASR存储配置](asr-storage-configuration.md)。Phase 2B已完成正式对象PUT前持久归属、跨实例scope核对与清理的fake验证；2026-11-05一条V01在新temporary链路真实完成并保持待审。真实私有OSS仍未配置联调，不能等同生产验收。临时上传48小时及官方不建议生产限制不变。

## 2. 模型配置、输出与版本

各能力独立Base URL/Key引用/模型/超时及能力检查。既有北京公共DashScope地址已测，官方仍支持；Workspace专属域名可外配，变更后做对应能力检查，不自动改地域。DeepSeek整理/问答关闭思考模式；文本和视觉兼容聊天，ASR适配原生句时间，embedding记录维度/归一化/模型身份。[百炼地址说明](https://help.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai)

模型名称是调用标识，不承诺供应商权重不变。任务、提示、原输入哈希、响应、用量、审核和索引版本分别留痕。失败或输出不完整显式标记；已有成功产物可按身份复用，不能把旧评分复制给新内容。

正式服务器模型认证调用尚未在本轮离线资源测试中执行；需在服务启动/接入补测验证，而不是用先前401网络检查当账号认证成功。ASR正式存储真实联调是后续手动启用managed模式的验收条件，其余真实业务整链路在各Phase验收。

## 3. 数据、引用和检索边界

- Markdown＋属性/附件为知识主数据；SQLite存任务、审核/版本元数据及可重建索引。它与原小程序数据库独立，不创建或修改原数据库表。
- 只有本人批准的当前版本参与正式检索；编辑/重传产生新版本，未审核、返工、删除/过期版本失效。文件与SQLite跨介质提交需设计暂存、原子替换及恢复，不将实验库的三表事务等同正式完整流程。
- 索引保留模型/维度/分块配置/内容版本，换embedding独立重建；更新与删除要同时维护正文、FTS、向量及有效引用，领域层已实现当前版本审核资格查询；正式索引与撤回/更新/删除同步尚待Phase 3实现。
- 问答实验主要索引获批来源笔记，尚未验证“原始证据优先＋笔记辅助”的双层生产召回。阶段实现中补原证据映射、视频起止时间/HTML位置深链并回归，不能直接宣称已支持精准跳转。
- 只展示实际引用的证据；拒答不展示无关候选。合法ID不代表事实支持，诊断Top-K/RRF分数不是置信度阈值。低相关性拒绝/重排及复杂无答案情况仍可按真实反馈完善。
- 研究阶段两篇HTML的表格/代码/原SVG已提取；2C1网页原先只有静态正文预览，2C2b已补齐模型整理，两份新结果待本人，旧评分不继承。SVG结构作为文本送模型，不是SVG图像视觉回归；JS动态图、图片/公式复杂类型没有充分样本。按PRD不执行任意脚本，缺失提示并接受补充静态导出。
- 目前三视频为本地文件，抖音分享解析/私密Cookie引用/受控下载已工程实现并离线验证，独立F2构造通过；真实账号、下载及云端可用性未测，保留上传兜底，不把离线构造当登录成功。
