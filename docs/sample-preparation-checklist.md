# 本人样本与评审准备清单

版本v0.2；2026-11-03。已有sources的3视频+2HTML可直接开始真实转换，不用先制作事实标准答案或补齐固定数量；未核实服务配置和价格不发付费调用。

## 1. 文件已够起步

- 保留三条原视频、两份原HTML及附件，来源ID、路径和SHA256由工具核对。
- 确认有权处理；不在聊天里发密钥/Cookie。本地视频不替代后续分享链接和Cookie验证。
- 两HTML可测正文、标题、代码、表格、SVG；图片、公式、JS交互图表缺口以后按需补，不阻塞本批demo。
- 原素材、运行结果、反馈不入Git；临时脚本/日志放 `tmp/`。

## 2. 配置后转换展示

各自配置文本、ASR、视觉/OCR、embedding的地址、模型及密钥引用，文本默认DeepSeek。核实价格与能力，每批先算最坏上界，预研总费≤100元，未知价格不按0。密钥不进入展示、导出和日志。

每份看真实转录、带时间画面文字/描述、摘要、来源笔记、版本、耗时和费用。片段探测不代表全片完成；无结果显示待处理，不展示伪造结果或自动高分。HTML安全静态提取，不执行原脚本和自动加载资源。

## 3. 本人做两件事

1. 给整体0–100分，关注意思、重点、数字术语、图表关系及摘要忠实程度；目标98分是主观评价，不是统计准确率。
2. 选批准（approve）、返工（rework）或拒绝（reject）；备注和标签可选。≥98分仍须批准，低于98分需返工，不用均分掩盖单份结论。

机器原输出与本人修订分别保存、分别评价。内容修改重新评；同版本最新决定为准，返工/拒绝撤销旧批准。预研只输出审核就绪，后续业务每份内容仍须本人审核后正式入库。

## 4. 按反馈推进

当前五份demo逐份达到目标并获本人认可，且能力/预算条件满足后，才进入真实问题检索试验。本人对照回答和出处，不强制60+20问题或Recall真值。选型由本人明确选择；版本变化先在本批demo回归重新评，不自动花钱重跑或切供应商。

历史50视频/500事实、gold及客观指标以后按需启用专项benchmark，不与个人评分混称。详见 [样本规范](sample-specification.md)、[当前协议](personal-review-contract.md)、[实施计划](PLAN.md)。
