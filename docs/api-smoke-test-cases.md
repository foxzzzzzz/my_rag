# API有效性探测实施前用例

日期2026-11-04。用户已授权测试本地.env的两个Key，按已确认2元探测上限及累计100元执行。任何输出不得含Key、Authorization或签名URL。

| 编号 | 场景 | 预期 |
|---|---|---|
| S01 | Key缺失/占位、非法endpoint或输入 | 不联网；脱敏错误，不打印原始.env |
| S02 | GET模型列表 | 只检查认证/枚举能力；404/列表中无模型不直接断言Key无效 |
| S03 | DeepSeek短文本、百炼单张合成蓝色图片 | 每模型最多一次付费POST；非空正常输出及usage为真实可调用证据，不代表质量验收 |
| S04 | ASR本地5秒音频 | 上传policy→上传→异步任务→查询→结果下载；检查服务原始句时间；不把仅取得task_id视为ASR通过 |
| S05 | 并发/重复启动、预算余额不足、网络超时费用未知 | 先原子预留不超过2元/累计100；未知费用保守占用上界，不重置账本或无限重试POST |
| S06 | HTTP401/403、余额/模型权限错误、网络失败、返回结构错误 | 分别记录无效认证/权限或余额/网络不确定/结构不符，不输出原始错误正文 |
| S07 | 提交ASR后中断或轮询超时 | 保存task_id以便恢复查询，不重复提交已知任务；不伪造转录或时间 |
| S08 | 重定向或第三方响应中的URL | 密钥仅发配置的官方API；上传/结果仅允许官方HTTPS地址，外部请求不携带API Key，不跟随任意重定向 |
| S09 | 探测报告 | 列模型、时间、HTTP状态、调用/结果、用量与保守费用及是否可继续；不宣称正式质量或RAG入库 |

离线单元测试使用假传输和合成数据；真实验证须另外运行并记录时间。先连通探测，不运行完整sources批次。
