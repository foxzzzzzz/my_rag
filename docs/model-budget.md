# 项目模型预算

在「预算」可查看项目累计上限、账本占用、剩余可用和已知消耗预估。预算以项目为累计范围，默认上限沿用 `budget.research_limit` 的 ¥100。视频和图文、模型网页、问答及分类建议的常规单次上限继续读取各自配置。抖音收藏的定时额度和单作品授权仍独立校验。

## 账本口径

- **账本占用**由共享 SQLite 的 `reservations` 金额累计。各业务沿用既有的预留及结算方式。新请求单独保存初始预留上限，账本占用扣减时仍可对照原上限。旧账本只有金额的记录继续按账本占用显示。
- **已知消耗预估**汇总有对应请求和可核算用量的记录，按项目配置价格估算。无法按请求可靠归属的记录标为「待核对」。实际费用以模型服务账单为准。
- **可用额度**等于累计上限减去账本占用，最低显示为零。将上限调至已占用金额以下时，已记录的费用和预留仍保留，新的预留会被拦截。无需新增预留的恢复仍可继续。

## 调整累计上限

登录后填写新金额，检查预览并保存。支持正数人民币金额和最多两位小数。保存记录旧值、新值和时间，修改基于读取到的版本，冲突时刷新后重试。设置和历史与预算账本一起备份。配置文件保留部署时的初始默认值，各业务继续使用相同账本路径，生产为 `/state/budget.sqlite`。

保存后的累计规则由新预留事务读取。单次和收藏授权继续生效，历史预留、任务状态和恢复授权保留。预算受阻任务可点击「查看预算」；具备可识别的单步续跑预留时，任务列表同时显示本步所需额度和项目当前可用额度。调整后从原任务入口明确确认或继续已授权的步骤。

视频或使用模型处理的网页任务因费用未确认而无法重试时，悬停、聚焦或轻点灰色「重试」里的感叹号可查看提示。展开「处理设置」，勾选「我同意所选视频或网页模型处理产生费用」，然后点击「重试」。保存预算和勾选费用确认均不会提交任务。

## 收藏转换额度与失败视频重新授权

预算页显示定时下载和转换各自已用的名额，两步使用同一个每日条数上限。每日转换金额独立设置，任务列表显示待处理原因。单条视频预留上限用于新授权。已在费用预检处失败且未提交模型请求的收藏视频，可在任务页点击「重新授权并重试」，也可从预算页打开同一弹窗。核对原授权和新报价，明确同意后用同一任务和缓存入队。单条新授权仍受常规单次上限与项目余额约束。

| 用例 | 验收条件 |
| --- | --- |
| MB05 旧库与设置 | 旧库的 5 条下载上限成为共同上限，旧金额继续读取部署配置。设置跨进程生效，过期版本被拒绝。 |
| MB06 派发与等待 | 费用充足时可下载、转换各 5 条。达到条数上限和金额不足时显示对应原因。同日已派发继续，跨日重算，手动批次独立。 |
| MB07 视频重新授权 | 32 帧与约 2113 秒音频的模拟任务从 ¥4.05 报价为 ¥4.12。普通重试、未同意、过时报价与超限均不入队。有效提交只恢复原任务，重复请求不重复派发。 |
| MB08 桌面与手机 | 预算页可保存三个设置，任务页显示条数和金额等待说明。重新授权弹窗可取消，低于报价或超过可用金额时不可提交。 |
| MB09 审核回归 | 仅回滚镜像时旧版仍可写设置，新版金额可恢复读取。兼容的历史处理策略可重新授权，不兼容时拒绝入队且保留尝试次数。关闭混合处理或手动回补时，保存额度不会重新启用功能。收藏配置暂时无效时，普通任务仍可查看。 |
| MB10 任务页直接授权 | 桌面和窄屏在任务页确认同一任务。取消或按 Esc 不提交并恢复焦点，未同意、金额无效或报价过期时不入队。网络失败后重试同一授权请求，双击确认只提交一次。预算页入口通过回归。 |

## 接口与验收

`GET /api/budget` 返回概览、业务单次上限、明细和调整记录。`PATCH /api/budget` 接受 `limit_cny` 字符串和 `expected_revision` 整数，沿用应用会话和 CSRF 校验。读取和调整都不发起模型请求。

| 用例 | 预期 |
| --- | --- |
| MB01 读取既有账本 | 旧表可读，累计占用和余额精确，缺估算项显式标为待核对。 |
| MB02 调整上限 | 校验金额和版本，拒绝过期修改，保留变更记录和原预留。 |
| MB03 执行预算 | 新预留事务使用当前上限，仍执行单任务限制；并发请求不能合计超额。 |
| MB04 浏览器验收 | 桌面和手机可查看、预览及保存，任务页可进入预算页，交互只操作隔离账本。 |

2026-11-20 本地验收通过。108 项后端和 76 项前端测试通过。Edge 在 1440px 和 390px 核对显示、修改预览、保存及调整记录，在 861px 和 768px 完成既有界面回归。测试使用隔离账本和模拟模型，无生产写入。
