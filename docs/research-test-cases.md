## 历史 v0.1 / 可选专项标注基准用例

日期：2026-11-03。此文件先于离线工具代码建立；这些是工具功能验收，不是模型质量实测。

| 编号 | 场景 | 预期 |
|---|---|---|
| R01 | 50 视频（30 dev/20 acceptance）、10 HTML、至少500人工确认事实的合法清单 | 样本准备检查通过；不宣称模型达标 |
| R02 | 缺数量、缺人工确认、空标注或不支持字段/类型 | 拒绝/列明缺项，不默认填充为合格 |
| R03 | 文件不存在、SHA256错误、重复ID或同文件跨开发/验收集 | 拒绝并定位到具体样本 |
| R04 | 路径穿越或链接指向样本根目录外 | 拒绝，不读取越界文件 |
| R05 | 冻结验收清单，再修改内容/标注/媒体 | 完整性检查失败；原锁文件不能静默覆盖 |
| R06 | 人工判定预测正确、错误、重复；正确映射原始事实和证据 | 准确率与覆盖率按约定分母计算；重复不能刷分 |
| R07 | 漏交一个验收样本、未知真值ID、重复预测ID、缺证据或未审定判定 | 拒绝评分，避免只挑成功样本 |
| R08 | 零预测、零分母、恰好98%、略低于98% | 无预测不通过；边界比较明确且不靠四舍五入通过 |
| R09 | 开发集结果或人工修订结果 | 可单独报告，但不能标记机器正式验收通过 |
| R10 | 已花费+未结算预留+新批次上界等于/超过100元 | 等于允许，超过拒绝；负数、NaN/Infinity、未知价格不放行 |
| R11 | 配置缺失、非法阈值/数量、JSON损坏 | 清晰失败并返回非零退出码 |
| R12 | CLI真实文件工作流 | 检查/冻结/评分/预算输出可读，输出明确标注离线工具边界 |

所有测试仅使用合成数据，放在项目根目录 tmp/ 下，并清理测试自身创建的文件。不得读取真实秘密或请求模型服务。真实样本、98%模型质量、费用与服务器性能另行验收。
