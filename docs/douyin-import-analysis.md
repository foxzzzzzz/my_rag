## 问题与路径

参考[TokBrain分析](../../TokBrain/project-analysis.md)及`app/services/f2_links.py`，复用F2单作品详情接口思路，不导入其数据库、应用服务或Windows DPAPI。只支持手动Cookie与单条分享链接，平台不允许下载或权限未知时拒绝，保留本地MP4兜底。

## 审查发现与修复

| 问题 | 最终实现与验证 |
|---|---|
| 请求前检查租约仍有提交竞态 | `commit_guard`在来源插入/去重的同一SQLite事务核对job/token/租约/锁；撤销后来源和任务均不提交 |
| 同步DNS可能无限占用worker | DNS等待有界；canonical作品ID不查DNS；连接固定已核验公共IP，保留原域名SNI及证书检查，不再次解析域名 |
| HTTP读取可拖延或截断 | 底层每次读取按剩余总时限设置timeout；空文件、声明长度与实际不符均失败并清理 |
| 可选下载缺配置阻断HTML | 过期锁恢复独立于Cookie/开关/配置；只有归属token匹配才释放维护锁，下载失败不阻断独立HTML流程 |
| 第三方日志初始化有文件副作用 | 在F2导入前安装NullHandler、禁用传播/记录及Loguru，覆盖无日志parse_json；离线验证不创建日志、旧sentinel不变 |
| SDK导入隐式同步Token出网，旧异步计数遗漏 | 导入暂时禁用自动Token生成；显式Cookie Token复用/必要时单次Token阶段；同步异步分阶段白名单、禁重定向；旧零网络结论收窄 |
| SDK传输默认关闭TLS校验并隐藏重试 | 桥接器统一覆盖HTTP/AsyncHTTPTransport为verify=True、retries=0，原API/父进程超时保持外部配置；真实SDK假传输回归通过 |
| 秘密与路径风险 | Cookie仅标准输入；独立Python `-I`、精简环境、隐藏子进程、有界输出；路径含junction/符号链接拒绝，失败只清本任务文件 |

相关离线测试覆盖DNS阻塞、固定IP与原域名TLS、socket响应生命周期、长度/大小、越界重定向、失租提交、共享锁恢复和秘密不返回。没有使用真实Cookie，不将fake下载计作真实成功。
