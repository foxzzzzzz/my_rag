# 本机网页启动验收用例

1. 使用验收副本配置启动：返回健康状态及 PID，退出启动器后服务持续响应。
2. 再次启动：识别已有本应用，报告状态，不启动或终止进程。
3. 端口被其他服务占用：明确报错，不终止占用进程。
4. 非回环地址、无效配置、不可用 Python：拒绝启动并提示。
5. 路径含空格：配置路径完整传递；启动失败时给出日志路径。
6. 默认 config/web.json 为正式配置；验收时显式指定副本，不修改原数据或读取真实环境文件。
7. 已完成HTML任务没有数值进度时显示“处理完成”，不能继续显示“处理中”。

## 2026-11-05 实测结果

- 验收副本启动后 `/api/session` 返回 200，启动器退出后仍可访问；重复执行识别 PID 18016。
- 指定正式配置而端口由验收副本占用时，报告配置不一致。
- `0.0.0.0` 配置被拒绝；不存在的 Python 路径启动失败。
- 临时 TCP 服务占用端口时报告无法验证，检查确认该服务仍在监听，随后按测试程序自身超时退出。
- 临时配置及服务日志位于 `tmp/web-server/`。含空格路径及启动超时场景尚未实测。
