# 检索预研实施前用例

日期：2026-11-04。前提：首轮五份真实输出均由本人评分并批准，版本绑定校验通过。仅创建可重建实验索引，不进入主体业务。

| 编号 | 用例 | 验收 |
|---|---|---|
| T01 | 缺少批准、源文件或输出版本变动 | 拒绝进入实验；保留原评分 |
| T02 | 标题/段落切块与固定窗口切块 | 无静默截断，稳定ID、材料与标题可追溯 |
| T03 | 中文词法、向量、混合检索 | 同一语料和问题对比，分别保存结果 |
| T04 | 两个embedding独立索引 | 验证数量/索引/维度/有限数值，不跨模型混搜 |
| T05 | 摘要与原始证据的关系 | 问答使用获批来源笔记；引用明确为整理文本，视频另可核对原片/时间 |
| T06 | 引用非检索ID、无答案问题 | 非法引用拒绝；无答案表现独立列出，不以合法ID证明语义正确 |
| T07 | 预算、超时、重复运行 | 先原子预留；无自动POST重试；未知费用保留上界，成功缓存绑定输入和哈希 |
| T08 | 评审页恶意文本与空评分 | 内容转义，无外部资源；分数不预填，反馈绑定问答输出 |

初筛问题由开发者按材料拟定，包含同义改写、术语/数字、跨来源及无答案问题。预期来源只用于初筛诊断，不是本人确认的标准答案；不得将来源命中率冒充事实正确率或正式Recall。本人可补充真实问题，评审前不宣称Phase 1C通过。

向量候选：百炼北京text-embedding-v4与qwen3.7-text-embedding-flash，同一API Key，维度1024；2026-11-04按官方兼容接口核实输入价分别0.5和0.125元/百万token。本轮调用预留上限15元，累计预研上限100元；不要求花满配额。

官方依据：[兼容接口、批量/长度/价格](https://help.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai)、[v4模型](https://help.aliyun.com/zh/model-studio/text-embedding-v4)。新增候选仍须通过账号实际调用，不将官方列出视为账号已开通。

本机小样本向量扫描只用于比较提取/检索效果；不证明SQLite扩展、1万块p95或Linux整机资源已验收。sqlite-vec及目标机性能在后续单独验证。
