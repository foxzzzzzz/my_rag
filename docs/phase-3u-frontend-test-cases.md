| UC07 | 当前版本变化、断线/重连、重复提交/409 | 老草稿不改绑新版；显示失效，重新加载需明确；CSRF、version/SHA、review_id幂等保持，不自动重试付费/审核 |
| UC08 | 已批准/返工/拒绝状态与人工修订 | 显示当前版本真实评分/意见，已批准不再“待本人核对”；修订生成新版本待审核，保留旧记录，旧引用失效规则不改 |

| UC10 | HTML重新生成与删除 | 生成仍需单次明确付费同意和expected_version；删除有明确确认/取消入口；取消无DELETE。只在隔离合成资料验证写入 |
| UC11 | 导入文件/分享链接、任务状态与开始/恢复/重试/取消 | 权利确认、上传限制、进度真实性和既有任务协议保留；导入不自动调用模型，禁用配置有说明；状态有语义提示 |
| UC12 | 问答首屏和范围选择 | 可直接看到问题输入/生成及付费同意；来源/主题/标签选择可展开，稳定ID传参；本地关键词检索无需付费，混合/生成/建索引仍需同意 |
| UC13 | 问答候选、回答、①引用、来源证据/技术字段 | 候选与实际引用区分，回答自然段/全文编号保持；证据可定位，技术信息折叠；无依据不给无关引用；失效引用不显示过期正文 |
| UC14 | 问答加载、错误、未启用/索引未就绪、事件流失效 | 真实状态与错误可见；不输出未经校验流正文，不自动发问/建索引；切换页保留会话内问答输入/结果，不重复付费 |
| UC15 | 1440px/780px/390px三页与辅助页 | 整页无横向溢出；中屏审核下置、手机表单/引用可用；主次/危险动作有区别，小字号普通文字对比度≥4.5:1 |
| UC16 | 键盘、阅读切换、弹层/错误 | 表单有label，焦点可见；来源切换/导航有合理落点，引用展开有名称和状态；错误/忙/空不只依赖颜色 |
| UC17 | 单元/构建/后端及独立Review | 先验纯逻辑草稿/阅读/状态，现有前端测试和隔离构建通过；后端适当全量回归，独立审安全语义和视觉；区分真实/合成证据 |
| UC18 | 发布正式入口及已有assets | 构建到隔离tmp后显式复制，index最后切换；旧评分/样稿assets保留，CSP不放宽；真实3份审核和214块索引保持；不调用真实模型验证UI |
| UC19 | 已有回答/证据，同版本再次审核；延迟提交时返回问答；含未知响应 | 审核开始与请求结束都改变本地审核epoch使旧结果失效；提交期间禁止生成/建索引/检索，仍保留问题；不得因version/eligible未变而保留旧引用，失败也不假定未提交 |

验收分层：纯逻辑/真实API离线回归 → 隔离合成库浏览器写流程 → 正式资料只读浏览器验收。合成模型响应只能证明界面/协议，不能证明新模型质量。3U-C工程通过后交本人3U-D界面验收，不能直接宣布Phase 4通过。

## 跨客户端审核失效

| 编号 | 场景 | 验收标准 |
|---|---|---|
| XR01 | A 客户端停在问答页，B 对已批准的同一版本再次提交批准 | 版本 ID 和资格都不变，A 在下一次成功轮询后撤下旧回答、候选及已展开引用，提示资料已更新并保留问题。无需切页或点击引用。 |
| XR02 | 新审核到达时 A 仍在生成或读取引用，或早发起的轮询迟到 | 旧结果或迟到响应不会重新显示，也不会覆盖较新的审核状态。 |
| XR03 | 周期轮询、仅保存草稿、重试同一个审核 ID | 普通轮询和未提交草稿不触发失效，同一审核 ID 的幂等重试不生成新审核标识。现有本客户端和服务端引用校验继续有效。 |
| XR04 | 先发起的刷新较晚读取到审核标识 2，后发起的刷新先读到标识 1 却因其他请求延迟最后应用 | 已应用标识 2 后，标识 1 不得回退同版本审核。下一次正常轮询不因恢复到标识 2 而清除重新生成的回答。 |

2026-11-10 本机验收。两个独立 Edge 会话连接同一个隔离 FastAPI/SQLite 库。实际提交同版本审核后，问答页在轮询时清除旧回答、候选及引用并保留问题。迟到的旧资料轮询、引用响应及生成流均未恢复旧结果，草稿和同一审核 ID 重试保持现有显示。问答及证据使用合成响应验证，不产生模型费用。
