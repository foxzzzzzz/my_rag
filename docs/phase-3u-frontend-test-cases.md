## 摘要与笔记排版

### Markdown 格式约定

视频和网页的 `summary` 与 `notes` 均为 Markdown 字符串，共用阅读页渲染器。保留段落、`#` 标题、`**粗体**`、HTTP(S) 链接和围栏代码。支持以下块级格式。

| 格式 | 写法与显示 |
|---|---|
| 有序列表 | 每项一行，例如 `1. 第一项`、`2. 第二项`，也接受 `1)`。保留起始编号，后续逐项递增。 |
| 无序和嵌套列表 | 用 `-`、`*` 或 `+` 标记无序项。子项用空格缩进，可混用有序和无序列表。各项可用空行隔开，列表项正文使用单行。 |
| 引用块 | 每行以 `>` 开头。引用内容单独呈现，并可包含段落或列表。 |
| 表格 | 用竖线分隔单元格，表头下一行用至少三个连字符标明每列，各行列数一致。有外侧竖线时，数据行也带外侧竖线。支持转义竖线和反引号包裹的竖线。表格可以紧接正文。省略外侧竖线时，表格后的含竖线正文需用空行隔开。窄屏允许表格区域横向滚动。 |

网页保留原始 Markdown，存储和导出仍使用原文。旧摘要中明确的中文枚举继续按既有规则显示。原始 HTML 按文本显示，链接只允许 HTTP(S)。

| 用例 | 操作与预期 |
