### D12/D14 安全错误回归
- 明确拒绝与权限未知分别返回安全代码；明确 allow_download=false 优先于回退字段。
- 解析异常和伪造错误只能返回通用错误，不泄露异常内容或凭据；任务保留白名单错误。
- D14 界面将拒绝、权限未知、解析失败映射为中文提示；未知错误不显示原始内容。
- 权限字段类型非法不得放行；任一明确拒绝与其他允许字段冲突时拒绝；桥接主程序及导入任务验证白名单传递与敏感信息屏蔽。
- 权限字段存在且非空但类型非法时，即使其他字段允许也须返回权限未知；合法明确拒绝优先于非法字段。

### D16：详情路径尾斜杠及三参数对照（2026-11-05）

- 固定成功 Cookie 和请求标头、直连 TLS，最多两次 GET、零 POST；禁止重定向，单次超时 15 秒，响应上限 1 MiB，间隔 1 秒。
- A 仅删除原详情路径末尾斜杠，保持原始 query 字节与顺序；B 使用相同无尾斜杠路径及已安装 fetcher 的三个参数。
- 离线断网合成测试验证路径/query 差异、边界与输出脱敏；真实响应仅内存处理，记录状态、目标 ID 匹配及生产权限安全字段。明确挑战、登录或策略拒绝时停止，不下载媒体。

### D17/D18 最小详情解析
- 配置校验模式、数字 aid/版本及响应大小；凭据只经 stdin。固定端点单 GET、零 Token、TLS 校验、禁重定向与代理、解压后限量；拒绝、超限、无效响应安全失败。
- legacy F2 显式模式及旧调用兼容；不自动切换。离线验证后最多一次真实 GET，不下载媒体。
- D18 配置要求读取块大小不超过详情响应限制；压缩流原始字节未超限但解压超限，以及截断 gzip 均须拒绝。

### D19–D24 下载与统一导入计划（待用户选择权限策略，均未执行）
- D19 配置与请求头：若经确认需要插件式媒体 Referer，以外部配置提供固定 HTTPS 来源并校验；仅媒体请求携带，分享请求不受影响。每次受控重定向重新验证目标；所有 CDN 请求均不含 Cookie、Authorization，拒绝私网/未允许域名，不记录完整媒体 URL 或凭据。
- D20 权限与拒绝：按用户选定策略检验许可分支；HTTP 拒绝、登录、付费、验证码等均安全失败、不尝试绕过，未知状态不伪报成功。现有 deny 样本在策略确定前不请求媒体。
- D21 完整下载：使用正常 URL、限定重定向/总时限/大小和磁盘阈值；记录字节数及完整 SHA-256，校验 Content-Length（存在时）；限制失败、短读、断流、超时及磁盘不足均删除临时文件并释放锁。
- D22 统一导入：隔离 workflow data_dir 与数据库，调用 enqueue 和 process_next 正常链路；验证 source 的 SHA-256 等于下载文件与导入 blob，文件可用 ffprobe 验证视频流；现有统一入口使用 ffmpeg 检查视频流，独立 ffprobe 是额外验收。核对任务、文件及可访问状态；不启动任何模型处理。
- D23 缓存与去重：同 URL 二次入队命中 work_id 缓存，不重复详情或媒体请求，source_id 相同；损坏、删除或哈希不匹配时不得使用缓存。记录真实请求计数而非仅声明上限。
- D24 隔离与清理：临时配置复制现有配置，仅临时启用与指定隔离绝对 data_dir；真实凭据仅内存或受保护输入，不写报告、命令行、子进程环境。核验原配置、原数据库不变，任务失败/租约丢失后无残留素材、锁或部分文件；实验限制、结果与 SHA 保存报告，不含媒体 URL、凭据和异常原文。

D19–D24 更新：用户已授权 authorized_playback 策略；仅使用平台返回的播放地址，不绕过实际 HTTP、登录、付费或验证码限制。离线验收通过后执行隔离真实闭环；默认配置保持全局关闭，最多 512 MiB、300 秒、单次 15 秒、5 跳，保留 8 GiB 磁盘空间，禁止模型调用和自动重试。
- D25 缺少媒体探测工具时任务保留 media_tool_missing 并展示安全中文提示，清理文件和锁；不输出路径或异常原文。
