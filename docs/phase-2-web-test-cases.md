# Phase 2C1 网页导入、进度与复核测试用例

日期：2026-11-05；编码前定义。本轮完成用户要求的三个网页流程；主题标签/附件ZIP/Obsidian重上传冲突作为2C2另验，不宣布整个Phase 2或Phase 3完成。

| 编号 | 场景 | 验收 |
|---|---|---|
| W01 | 启动/刷新/空库 | React页面真实连接FastAPI，空态、失败态、刷新持久记录正常，不编造素材或分数 |
| W02 | 选择/拖拽HTML和MP4 | 明确授权确认，显示逐文件上传结果；原文件名仅元数据；重复字节返回同一来源/任务 |
| W03 | 超限/伪格式/未授权/流式异常 | 前后端都校验；未知Content-Length仍逐块限量；暂存清理；低磁盘拒绝，无队列记录 |
| W04 | 明确开始与重复点击 | 导入不自动付费；HTML本地处理，视频需明确同意调用模型；持久派发表幂等，全局一个worker |
| W05 | 进度与错误 | 展示真实状态/阶段、已完成帧/阶段数量及待处理/失败原因，不编造百分比；轮询不阻塞页面、卸载停止 |
| W06 | 派发重启恢复 | 未执行可安全重排；已外呼未知不自动提交，显式resume沿2B规则；取消后不发布 |
| W07 | 笔记与原证据 | 正文/摘要/转录/视觉可查看；视频可播放且按证据时间跳转，帧来自同一来源、哈希匹配；HTML原件仅附件下载 |
| W08 | 正常评分 | 有限0–100分、审核人、明确决定；approve需≥98；写入当前version+SHA，刷新后仍显示，资格只由领域层决定 |
| W09 | 拒绝/返工/低分 | 低分approve拒绝；高分reject同样无资格；最新rework/reject即时撤销，不替用户自动打分 |
| W10 | 并发/旧版本/重复反馈 | 旧version或错SHA返回409；同review_id幂等不同内容冲突；刷新前不得用旧表单批准新内容 |
| W11 | 人工修订 | 乐观expected_version；保存新human_edited版本后重新评分，保留机器原版和历史决定 |
| W12 | 安全显示与访问 | 文件名/正文/模型文本只作文本，不执行script/事件属性，不获取原HTML外链；不返回Key、签名URL、lease_token或任意服务器路径 |
| W13 | 本机访问保护 | 默认只绑定127.0.0.1；Host白名单、会话与写入CSRF/Origin校验；未经授权跨站写入失败，无默认公网暴露 |
| W14 | 删除/取消/重试/导出 | 复用领域一致性；删除即失效，取消旧令牌不能完成；Markdown为下载，含ID/版本/审核状态，重复下载可用 |
| W15 | 浏览器集成 | 真实HTML上传→处理→查看→评分/撤回→修订/冲突；自动评分只用明确测试素材；真实视频已有产物只查看不批准 |
| W16 | 交付与回归 | 前端锁文件/构建通过、API/派发回归通过、桌面/窄屏可用；无新模型调用，完整生产登录/HTTPS/资源在Phase 4验收 |

## 2026-11-05结果

本轮范围通过：235项Python回归中233通过、2项平台跳过；前端7组与构建通过。真实浏览器完成HTML上传、明确启动、详情更新、评分/撤回/修订、多标签页旧表单保护、Markdown下载及视频播放/帧定位；仅测试HTML写功能分数，真实视频仍待本人。故障与访问限制通过API/领域注入测试，未冒称云端资源/生产认证已验收。证据见[专项验收](phase-2-web-validation.md)。
