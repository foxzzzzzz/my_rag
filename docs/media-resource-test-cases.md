# 云端媒体资源压测实施前用例

日期：2026-11-04；依据PRD v0.6，当前只做FFmpeg与资源研究，不调用模型、不配置Key，不操作既有业务。

| 编号 | 场景 | 预期 |
|---|---|---|
| M01 | 素材缺失/哈希变化、输出目录冲突 | 停止并说明，不写原视频或旧报告 |
| M02 | 三条视频逐条完整解码、音频和抽帧 | 全部真实执行，记录退出状态、时长、帧数/音频长度及日志；不以抽样代全片解码 |
| M03 | 资源采样 | 记录本进程树采样RSS与整机total-available代理值、Swap、磁盘；两种内存口径不混淆 |
| M04 | baseline或执行期间资源不足 | 根据外置阈值停收/停止自己的子进程，保留报告，不停既有网站/数据库 |
| M05 | 子任务超时与主动中断 | 只终止本工具启动的FFmpeg及其子进程，记录正常中断；异常不冒充完整通过 |
| M06 | 临时产物清理 | 只删除本次独占work下列入清单的产物，验证边界，保留原视频/日志/报告 |
| M07 | 隔离打包与复跑 | 不带密钥，版本/配置/源码及素材SHA可核对；每次新run目录，不覆盖旧结果 |
| M08 | 共享业务共存 | 保留现有服务运行；没有业务健康接口时明确未测业务响应，不假称无影响 |

默认单任务、FFmpeg解码/输出线程2、滤镜线程1，采样间隔0.2秒。整机内存以MemTotal-MemAvailable的采样代理值对照3,000,000,000字节（3.0GB，约2.79GiB）；不是精确进程RSS或无采样遗漏的绝对峰值。可用内存<512MiB、数据盘可用<8GiB时停止测试。正常服务波动可能触发，不能自行清缓存/停服务来通过。

先本机离线用例与真实小样本冒烟，再由用户在Linux服务器跑真实3条；本机通过不当作目标机通过。未实现业务队列/磁盘停收API的生产验收仍留到后续实现，研究工具的保护不能冒充正式系统能力。
