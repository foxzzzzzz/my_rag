## 实现与修复

正式索引必须使用当前批准、分数达标且长期内容校验通过的版本；原始证据分块，模型/版本/维度/分块及知识库身份绑定空间。staging完成后复验、原子发布；检索、生成前后及引用打开重新检查资格，过滤先于TopK。正文、FTS、vec0及用于范围内计算的向量blob同事务写删，旧结构明确要求重建。

独立Review及联调发现并关闭：相同维度但返回模型错误仍被接受；分类更新误删有效向量；异常模型输出已有用量未计费；人工修正文却沿用错误旧证据；关闭开关及检索模式校验不足；API技术错误直接暴露到页面。人工证据保留父版，未核对时间不继承旧时间或帧定位。

付费适配器独立使用已有两Key，持久请求ID/指纹、调用前预留和共享研究预算，已知usage先结算再验证内容，未知状态保留预留，不自动重发。问答采用受校验的进度/回答/结束事件，未校验正文不透传。
