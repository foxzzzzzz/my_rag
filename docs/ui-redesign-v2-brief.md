# 第二版设计简报：日常知识管理工具

## 反馈与判断

第一版未获本人批准，用户认为“AI味道太重”。当前主要问题是：每页重复英文眉题、宣传口号、36px标题、奶油底与墨绿品牌块、零散细线和宽大留白形成通用展示页；即使功能正确，也不像长期使用的笔记工具。第二版从用途重排界面，不靠新增装饰制造差异。

## 方向与小型设计系统

对象：单人日常导入、检索、阅读、核对、提问。采用文档管理软件的操作密度：中性浅灰侧栏、白色内容面，选中和主要动作少量蓝色。不是营销首页，不采用海报、报纸排版或对话机器人拟人化。

基础色：白`#ffffff`，应用灰`#f7f8fa`，侧栏灰`#f1f3f5`，正文`#24282e`，次级文字`#606874`，操作蓝`#345ca8`。最终tokens可按实测对比度微调；参数含义需注释。

中文统一系统无衬线字体（Segoe UI/Microsoft YaHei/PingFang）；页面标题22–24px、列表标题14–16px、正文16px/行高1.8、元信息12–13px且可读。紧凑顶栏、普通工具按钮、稳定行高；圆角4–6px，用边界表达布局，不堆卡片/阴影。

### 资料库

约200px浅灰侧栏：资料库、问答和可操作的主题入口，底部仅保留必要状态。主区标题和导入按钮同一行，搜索/类型/审核/主题过滤是紧凑工具条；资料以有列关系的列表展示：标题/摘要/来源和标签，审核状态与日期对齐。桌面4份资料应能自然查看，无一行150px的展示卡；手机把次要列折叠到行内。

### 详情与审核

顶部返回/位置和22–24px资料标题；来源/版本/状态为普通元信息。正文以文档阅读为主，正文与原文/音画证据切换有明确操作。右侧约280px审核面板，评分、意见、保存、批准一眼可辨；手机转为正文下方审核。管理操作折叠且明确演示，不出现可执行但实际上无响应的按钮。

### 问答

显示普通“问答”标题和紧凑提问区；不放英文大字或品牌宣言。预置问题和资料范围靠近输入，回答像笔记正文，有短标题、段落/要点、①脚注及独立来源区。说明演示/付费的事实各出现一次即可，不在每段重复说明。索引诊断降为次级设置。

## 保留的真实约束

方向复核：灰白本身也可能成为模板，因此用本项目的任务关系决定结构，而不靠配色宣称独特。主要对齐关系如下，内容左对齐，审核表单有独立操作列：

```text
资料库  [导航/主题] | 资料库                 [导入]
                   | 搜索  类型  审核  主题
                   | 标题/摘要/标签     状态    日期

详情    [导航/主题] | 返回 / 标题 / 来源
                   | 正文 | 来源证据     [评分/意见]
                   | 文档内容            [保存/批准]

问答    [导航/主题] | 问答 / 范围
                   | 提问输入              [生成]
                   | 回答自然段、①和来源证据
```

四份演示资料与99/100/100预置已批记录、98分门槛不变；保存与批准分离；草稿在本页内存保存，刷新复位。①仍可展开证据。演示内容不得暗示新的真实模型结果。禁止fetch、真实API、localStorage或正式评分写入。
