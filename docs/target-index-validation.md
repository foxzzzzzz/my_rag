- `scope=local_offline_synthetic_load_not_target_server_acceptance`是同一跨平台工具的固定研究标签；执行环境字段明确是Linux目标机，不应因标签里有local就当作Windows结果。

- 来源约束查询只测正确性，尚未单独压测过滤路径；正式业务审核状态/版本隔离、备份恢复仍待实现与验收。
