# Phase 2D综合验收补充契约

日期：2026-11-05；PRD v0.16。编码前用例I01–I18以及下列细化先于实现。补齐PRD已有分类建议与全局执行互斥，不增加供应商/Key，不提前实现Phase 3索引或Phase 4云端。

## 取消与实际执行分离（I04）

取消/删除立即撤销任务提交资格、禁止新版本或来源落库；不等于正在执行的同步HTTP/FFmpeg已停止。原执行在finally或真实进程退出之前，第二Web/CLI worker、HTML/video的run/resume、抖音下载/清理及AI建议不得开始另一重任务。

实现须将持久状态/租约与本地执行互斥分离，可采用跨进程可恢复锁；不得靠取消立即清租约就放行，也不能仅靠一个Web线程串行假定无第二进程。真正进程退出后占用可恢复，远端未知POST仍按原规则保留needs_attention，不自动重发。续租/取消不得导致执行中互斥先释放；锁顺序应避免SQLite事务和文件锁互等。

故障用例：用Event阻塞注入runner，取消或删除后从第二store/worker尝试HTML/video/resume/下载均不得执行；原runner返回后允许后续任务，原任务不能提交；异常/硬退出恢复不遗留永久死锁；同一执行内部的合法claim/heartbeat不自锁。

## AI分类建议（I10）

- 外置配置控制启用、模型配置引用、提示词、上下文/目录/输出限额、超时、共享研究预算/单次预留与价格。只用既有text服务，不新增Key。缺配置/无付费同意/预算不足/资源忙时不发请求。
- 生成与应用分离。POST生成需allow_paid=true及当前正文版本/分类修订号；在发模型请求之前持久记录请求状态并保守预留预算。同步生成可以在线程池等待，但必须取得与后台worker共享的全局执行占用，不允许并发第二模型任务。
- 建议记录source/version/content SHA、元数据revision、目录快照摘要、provider/model/usage/费用及提示/参数指纹、状态。只保存结构化安全结果，不保存秘密/原始异常；重启后未决生成标记needs_attention，不自动重试未知POST。
- 建议只接受目录中的topic/tag稳定ID；未知ID、类型错配、重复/超限及任意原始模型指令拒绝。新主题/标签只能是待确认候选名称，不能在生成时建目录或改来源。模型内容作为数据，不执行指令/脚本。
- UI呈现已有分类建议和候选新分类，用户可选择应用/拒绝，逐项明确确认新名称；可部分接受，默认不勾选新分类。应用采用追加选中项，保留手工已有分类；不改正文/评分。
- 应用同一事务核对source未删、正文版本/SHA、分类revision及目录摘要；创建用户明确确认的新分类、关联和幂等回执一并提交。旧版本、目录/别名变化或分类并发均返回明确冲突，不静默覆盖/重建。不允许上传自报建议/评分绕过服务端信任根。
- 持久状态至少区分生成中、可确认、已应用、已拒绝、失败、需处理；重复应用幂等，已拒绝不可应用，重新生成属于新明确操作而非自动POST重放。

接口约定（同现有会话/CSRF保护）：GET `/api/sources/{id}/classification/suggestions`查询最新记录；POST同路径生成；POST `/api/classification-suggestions/{id}/apply`应用所选已有ID/逐项确认的新名称；POST同前缀`/reject`拒绝。最终字段由实现记录在指南，接口返回不得包含Key/完整私密路径/原始远端异常。

细化用例：无同意0调用；成功生成不改分类；已有ID/别名归一与未知ID拒绝；新分类未确认0创建；显式确认原子创建；应用/拒绝幂等；正文/元数据/目录/删除冲突0修改；未知POST不自动重发且预算不盲目释放；全局busy0调用；模型结构/输出限额/错误安全码；UI付费提示与新分类默认未勾选；真实评分保持不变。
