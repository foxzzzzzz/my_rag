# Phase 2D综合验收测试用例

日期：2026-11-05。用户已确认2C2e当前授权样本验收，授权启动2D。本文先于新增代码/用例实施；依据PRD v0.15，规格补全须先更新PRD/契约。完整Phase 2验收不等同Phase 3正式索引或Phase 4云端上线。

## 测试数据与执行约束

- 自动化流程使用独立tmp数据库、合成HTML/模型返回和测试评分，明确标记synthetic，不写入真实资料库或代替本人评分。临时日志/配置/模拟数据只存被忽略的tmp。
- 真实证据只读核对既有来源/产物、D05下载素材及SHA/缓存；不重复下载已通过作品，不重复调用ASR/视觉/文本模型或修改真实评分。需要新增真实调用时先列验证目的、费用/次数和停止条件。
- 各项记录实际执行命令、结果、关联文件及证据类别；fake证明流程与故障处理，不能当真实服务、Linux资源或本人质量评分通过。
- 全局抖音下载默认关闭、私密.env不变；不在输出/报告中写入Cookie、签名URL、模型密钥或原始远端异常。

## 综合用例

| 编号 | 场景 | 验收标准 |
|---|---|---|
| I01 | 本地HTML/视频及链接下载统一素材入口 | 稳定source/note ID、SHA去重；多入口同原件只一份素材；下载成功仅排待处理，不隐式模型调用 |
| I02 | 导入→持久派发→处理→待审核 | Web/领域层同状态，只有明确处理请求才派发；重启可见；失败不产生正式资格 |
| I03 | 同文件重复、删除后重导入、旧下载缓存 | 不错误返回已删除来源、不复用失效版本或孤儿缓存；数量/缓存身份与当前可见来源一致 |
| I04 | 单worker与全局媒体互斥、租约失效 | 视频处理/链接下载/清理互斥保持；失租后禁止提交版本/来源；恢复不重复付费POST |
| I05 | 视频时间证据/HTML结构证据→永久附件→当前MD | 片段/关键帧/原HTML关联当前source/version；临时work移开后永久附件可读；无外链/脚本执行 |
| I06 | 本人评分控制流与最新决定 | 测试评分只入隔离库；≥98且approve、同步校验通过才具正式资格；低分/拒绝/返工/撤回即时无资格 |
| I07 | 修订/重处理后旧评分隔离 | 新正文版本待审，保留旧版/历史评分，不沿用旧批准；CAS冲突无覆盖 |
| I08 | MD同步失败、损坏及恢复 | 写盘失败显式待同步；文件内容/附件校验失败不具资格；重放恢复，不误改版本/批准 |
| I09 | 分类、别名、批量与内容版本交互 | 来源元数据CAS、目录重命名/别名归一、批量逐项结果；当前MD及过滤/导出一致，分类变更不制造正文评分 |
| I10 | AI建议已有分类/新主题确认 | 对照PRD核对能力存在；建议与应用分离，用户显式接受/拒绝，新主题须确认；不自动改分类/评分。请求付费、预算、建议结构、删除/版本/目录变化均有边界；缺项须补实现，不能直接略过验收 |
| I11 | 可编辑MD/附件ZIP完整往返 | 稳定ID、基准版本/元数据修订号、证据相对引用；上传预览不立即变更；明确应用后新版本待审，附件不被上传替换 |
| I12 | 预览后并发、删除、重放与分类冲突 | 应用再次CAS；旧基准需明确冲突选择，不静默覆盖；幂等回执不重复版本/评分 |
| I13 | Web任务/复核/分类/导出联动 | API及页面展示当前状态，切换来源/版本不误绑定表单；长任务刷新/重连与错误提示一致 |
| I14 | 磁盘/文件大小/超时/中断保护 | 正式配置保护值外置，失败清理仅自身临时文件，素材/永久证据/同步记录一致；不把Windows功能测试当目标Linux压测 |
| I15 | 下载策略与CDN凭据边界 | authorized_playback按用户授权执行，strict可显式配置；实际HTTP拒绝不自动切模式/出口；Cookie/Auth不发媒体CDN，固定Referer、域名/IP/TLS/重定向/限额保持 |
| I16 | 恶意HTML/ZIP/路径/CSRF与秘密 | 无任意脚本/外链执行、路径穿越/压缩炸弹/CAS权限冒用；Cookie/密钥/签名URL不进入API/MD/ZIP/报告 |
| I17 | 既有真实素材与审核现状只读清单 | 列出现有实际产物和本人未审核项，不移植预研旧评分；D05核验报告继续有效，不假称全部内容已批准 |
| I18 | 全量后端/独立SDK/前端/构建及独立Review | 新增综合用例及已有回归通过；跳过原因明确；关闭本轮实质问题后再跑最终快照，不累计重复计数 |

## 阶段判定

先发布用例→独立审查差距→执行隔离综合验证→修复并回归→出具证据矩阵/剩余项。若明确PRD能力尚缺（例如AI分类建议），先补齐必要规格/代码/测试，不以局部回归通过替代全范围验收。

自动化与本机UI验证、既有真实调用证据、本人内容评分、目标机部署资源验证分别记录。真实资料保持待审并非允许进入正式问答；Phase 3/4不因本轮任何测试自动开放。不得擅自降低功能、质量、下载或预算规则，不自动commit/push/tag。
