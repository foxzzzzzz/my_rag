# Phase 2C2a / 2C2b 编码前验收用例

日期：2026-11-05。先发布本用例，再实施代码。合成数据只验证机制，不代替本人评分。

| 编号 | 场景 | 预期 |
|---|---|---|
| K01 | 新机器版本、人工修订 | 稳定 note_id=source_id；每版本 Markdown、结构化证据与校验清单持久保存，旧版本不覆盖 |
| K02 | 同一版本通过、返工、删除、编辑新版 | 当前入口准确反映状态；旧批准不迁移；删除不继续展示为正式知识 |
| K03 | 写盘失败或进程中断 | 有持久待同步记录；不得把未同步文件当成可用知识；重试不新增内容版本/评分，可恢复一致状态 |
| K04 | 文件损坏、路径穿越、符号链接 | 校验失败并停止使用，不读写根目录之外或静默接受损坏 |
| K05 | CLI 和网页导出相同版本 | 共用一个 Markdown 渲染协议，来源/版本/内容哈希与当前审核状态一致 |
| K06 | 视频关键帧迁移后移除临时 work 目录 | 长期附件仍按 SHA 校验并可取；未迁移旧数据可显式补建；不自动删除旧缓存 |
| K07 | 分离演示与正式目录 | 默认真实开发目录不混入自动评分测试资料；迁移只读旧输入，幂等且不改历史评分 |
| K08 | 备份恢复边界 | Markdown/附件可脱离应用阅读；恢复任务、审核历史仍需 SQLite 一致性备份，不宣称仅 MD 可还原整个系统 |
| H01 | HTML 含正文/表格/代码/SVG/公式/外链 | 静态提取保留可识别结构；不执行脚本、不请求外链；不可识别内容明确告警 |
| H02 | 网页离线预览与模型整理 | 明确区分两模式；模型调用须明确授权且受配置开关控制；预览不能冒充 AI 摘要 |
| H03 | HTML 真实模型整理 | 使用已验证 DeepSeek 文本配置及提示，输出非空摘要/笔记、完整提取证据、模型/参数身份和用量 |
| H04 | 超预算、缺 Key、超上下文 | 付费前失败，无 POST；未知价格不按零计，无静默截断 |
| H05 | 超时/未知同步 POST、已完成缓存 | 未知请求转人工处理，不自动重复 POST；已完成阶段可安全复用 |
| H06 | 取消/租约失效/进程恢复 | 旧 worker 不落新版；任务及付费阶段持久状态可查；保持单 worker |
| H07 | 两份真实 sources HTML | 新链路运行、保存新版本与费用报告；原文件不变，原评分不沿用，待本人复评 |
| H08 | 跨阶段回归 | 既有视频/审核/API/前端回归；模型文本按文本显示，外部指令视为来源数据 |

本轮不把上述通过等同 Phase 2 整体、Phase 3 或生产云端验收。正式重传冲突、ZIP、标签及链接另列用例。
