# 正式索引与真实问答评分交付用例

日期：2026-11-06；依据PRD v0.18及R01–R21，用户明确授权用当前三份批准资料构建索引、生成真实回答供本人评价。以下用例先于本轮临时运行/展示脚本；沿用已有正式API和模型，不新增业务功能或改变评分规则。

| 编号 | 操作 | 验收标准 |
|---|---|---|
| L01 | 调用前快照 | V01/H01/H02当前版本、SHA、最新review和eligible均核对，工程样例不合格；读取累计预算，估算构建/问题向量/回答保留额，不输出Key或Cookie |
| L02 | 正式索引 | 通过现有正式build API构建，不复制预研向量；只包含三份当前批准来源，1024维/返回模型校验，生成ready空间；已ready且来源版本不变时不重复付费重建 |
| L03 | 逐题真实调用 | 视频、两份HTML、跨来源比较及无答案问题，使用正式hybrid/ask接口；每题稳定request_id，串行执行、无未知POST自动重发；保存阶段结果和安全错误 |
| L04 | 引用核验 | 每个实际引用经正式citation接口复验，source/version/SHA一致、字符摘录匹配；记录HTML证据索引/字符范围或真实视频时间/帧SHA，不编造定位 |
| L05 | 无答案 | 预先列明无答案对照题；报告实际insufficient_evidence和引用数，若未拒答据实记录失败，不能改写模型结果为正确答案 |
| L06 | 费用与业务不变 | 保存本轮请求model/usage/实际估算或未知预留，累计研究预算≤100元；对照资料版本/审核快照，不能代填分数、approve或改源资料 |
| L07 | 评分页 | 复用已有HTML评审器，按run_id/question_id/输出SHA绑定；每题分数/决定留空，文本安全转义，拒答无无关引用，可导出本轮JSON反馈；本人评分才判断质量 |
| L08 | 交付 | 保存真实结果、索引状态、引用检查和费用；网页可查看与评分，更新PLAN/Todo/CHANGELOG和真实验收记录。未收到问答评分前不宣布质量闭环或进入Phase 4 |
| L09 | 技术正文方括号与缓存恢复 | 真实Q04响应已缓存但正文含TOML `[sandbox]` 被误当引用而拒绝：允许普通方括号字面文本，只把完整64位十六进制片段标识视为引用；未知64位ID、正文/结构化集合不符仍拒绝。修复前补例，修后用原请求ID复用已完成向量/回答缓存，不新POST、不改写原答案，最终引用仍逐条资格复验 |
| L10 | 拒答规范化与缓存恢复 | 真实Q09的insufficient_evidence=true却带候选引用：在类型/结构及全部上下文资格复验后统一返回既有固定拒答和空引用，不展示原模型回答或候选引用；保留原响应作为协议偏差记录。insufficient=false时未知64位ID/引用集合不符仍拒绝；撤审上下文不能靠拒答绕过。原请求缓存恢复不新增POST，不把规范化当模型自行遵守协议或质量评分通过 |

本轮计划9题：视频2题、OpenManus 2题、smolagents 2题、跨来源1题、无答案2题。题目由开发者拟定，不作为人工gold，不以结构合法代表语义正确。任何模型失败不伪造答案或静默换模；若出现真实接口适配问题，先补针对用例再修复并记录再次调用成本。
