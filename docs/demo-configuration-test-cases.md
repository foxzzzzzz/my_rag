# Demo配置工具实施前用例

日期2026-11-03。以下用例先于本轮配置检查代码实施，不发模型请求，不读取/打印无关秘密。

| 编号 | 场景 | 预期 |
|---|---|---|
| C01 | 两Key为空或只有占位符 | doctor清楚列出缺少的变量名，非零退出，不发网络请求 |
| C02 | dotenv有两Key，操作系统环境变量覆盖其中一个 | 按环境变量优先；只报告已配置/缺失，不输出值/前后缀/长度/哈希 |
| C03 | .env有引号、注释、UTF-8 BOM或非法格式 | 安全解析简单赋值，不执行shell、不插值；错误不泄露原行 |
| C04 | setup被重复运行，现有.env已有内容 | 只在不存在时创建，不覆盖现有密钥 |
| C05 | FFmpeg通过显式环境变量、PATH或tmp便携工具找到 | 仅本地存在性/执行版本检查，区分未配置与有效路径 |
| C06 | sources下3视频2HTML、重复文件或目录缺失 | 列出数量、大小、SHA及问题，不伪装模型结果；源文件不修改 |
| C07 | 非法配置、无效URL、模型字段缺失、预算负值/NaN/超100 | 清晰错误、非零退出，不打印原始配置/密钥 |
| C08 | 两Key和素材/FFmpeg均就绪 | 只标ready_for_smoke_test；service_verified=false，未联网，未花费 |

配置通过不是模型可用性、余额或质量通过。真实调用运行器在配置完成后接入；必须先实现累计预算预留/结算、有限重试、任务恢复及输出原始证据，不能拿doctor替代真实探测。
