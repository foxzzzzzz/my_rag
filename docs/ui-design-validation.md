## 独立Review与修复

Sol High负责设计评审，Terra Medium实施样稿与修复，主代理进行浏览器验收。独立评审采用源码与截图，未独立点击浏览器；上表交互结果由主代理实测。

- P1：导航/切证据丢失审核意见及旧草稿回退。已改为输入时保留内存草稿、保存评分与意见、批准后展示意见；往返复测通过。
- P2：阅读切换丢失焦点、伪tab键盘语义、弹层无关联名称、批准后焦点失效。改为带aria-pressed的普通按钮并恢复焦点；弹层关联标题、关闭归还有效入口。
- P2：范围选择看似可用但不生效。固定“已批准演示资料”并禁用选择、明确提示；正式范围选择在3U-C接真实接口。
- P2：初次截图在路由/尺寸切换中抓到旧画面。已在确认页面后重截；未以旧截图判定通过。
- P2：辅助文字对比度偏低。muted改为`#5f7066`，相对canvas/paper分别4.80:1/5.21:1；手机导入按钮也已改为单行。

复核未发现剩余P0/P1。普通字体放大、屏幕阅读器、多浏览器、更多长文/加载失败等仍需正式接入阶段继续验证，不宣称无障碍全面达标。
