# 简化评审流程实施前用例

日期2026-11-03；依据PRD v0.2。先列用例，再实施离线评审工具；不开发未开放的生产业务、不调用模型。

| 编号 | 场景 | 预期 |
|---|---|---|
| P01 | 真实转换产物：来源、run/方案/输出版本、转录/视觉/摘要/笔记、费用和耗时 | 生成可本地打开的评审页，明确展示是personal_review，原文按文本转义 |
| P02 | 本人填写百分比分数+批准/返工/拒绝，备注和问题标签可选 | 导出JSON评分；CLI汇总和页面一致；无须gold或事实逐条映射 |
| P03 | 98分批准、97分批准、100分拒绝、未评分 | 仅98分批准满足默认审核条件；评分不等于自动入库 |
| P04 | 0/100边界、负数/超100、NaN/Infinity/布尔、缺审核人 | 非法记录拒绝，不能用空分数当0或默认高分 |
| P05 | 内容/来源/方案/run/输出版本变更，旧反馈重放 | 哈希或身份不匹配拒绝，不能继承旧批准 |
| P06 | 一份合格另一份低分或未审核 | 逐份展示，无全部通过标志；均分不能掩盖未通过项 |
| P07 | 同版本先批准后返工/拒绝，重复review id或歧义顺序 | 最新明确决定为准；重复/非法记录拒绝 |
| P08 | 来源或输出含script/闭合script标签/恶意URL | 页面转义、不执行源HTML或模型输出脚本，不自动加载外部资源 |
| P09 | 无真实结果、空正文/只有摘要、simulation/placeholder来源 | 不生成可批准产物；缺字段明确错误 |
| P10 | 现有客观工具回归 | 旧功能仍可用，但输出声明非当前工作流入库门槛；预算100元不变 |

测试文件仅用tmp/合成数据。测试通过不代表已取得真实ASR/OCR/摘要结果或本人已审核。
