# Phase 3U：个人知识库UI设计简报

> 2026-11-06更新：第一版未获本人批准，反馈为“AI味道太重”。本文件保留历史提案；当前方向以[第二版简报](ui-redesign-v2-brief.md)为准，不继续锁定暖底/墨绿风格。

## 目标与范围

Phase 3工程与本人样本问答反馈已完成。在Phase 4前增加3U：设计规范/skill → 三页交互样稿 → 本人确认 → 正式前端统一实施与回归 → Phase 4部署。

本轮只交付资料库、资料详情与审核、问答三个页面的样稿。保留现有React/Vite、FastAPI、单worker及模型/存储选择；不增加运行时服务。样稿使用清楚标记的演示数据，绝不调用真实审核/问答/付费接口。用户确认前不替换正式页面。

## 视觉方向：安静的个人知识工作台

- 浅暖灰底、白色阅读面、深墨文字、克制的青绿色主动作；细边框和小面积主题色，不用大片渐变/数据大屏。
- 固定窄侧栏，清楚显示当前位置；桌面主区最大约1440px，留白用于分组与阅读，不保留无内容的大空面板。
- 正文16px左右、行高1.8、阅读行宽约68个字符；标题/说明/元信息有层次。颜色/字号/间距/断点外置为带说明的CSS tokens，演示数据和交互默认值独立配置。
- 主按钮、次按钮、文字操作、危险操作有明确等级；图标配可访问名称。只用本地资源/原生SVG，无远程字体、追踪或新依赖。

## 三页结构

### 资料库

主标题“资料库”，简短说明和一个“导入资料”主入口。紧凑搜索/类型/审核筛选；主题在侧边或轻量标签中浏览。主画布显示可读标题、内容摘要、来源图标、主题/标签、审核状态和更新时间的资料卡/列表；不默认空置右侧大面板。准备三份熟悉内容和一份待审演示材料，示例标题用人类可读名称而不是长文件名。导入入口仅展示交互说明，不实际导入。

### 资料详情与审核

顶部返回资料库/面包屑、标题、来源及状态。主列阅读整理正文，视频可切“整理正文/语音与画面证据”，HTML为“整理正文/原文证据”。右侧为紧凑审核区，展示版本、评分、意见和明确批准动作；已批准不继续提示待审核。支持待审演示材料看完整流程。管理/导出/重新生成/删除是次级或折叠入口，付费和新版本重审边界有说明，不执行真实操作。小屏切为单列，审核入口仍可达。

### 问答

提问输入与资料范围为首要入口，索引状态缩为小标识、高级设置折叠；避免大型多选框挤掉输入。预置一个有答案问题及一个无依据问题，示例回答明确为演示。回答使用文章段落、列表与正文①脚注，来源证据单独呈现，ID/版本折叠。清楚展示“实际发送会调用付费模型”的确认约定，样稿只切换预置内容。

## 质量与交付

先执行[U01–U11](ui-design-test-cases.md)。桌面与390px浏览器点验，检查正文密度、对比、焦点、空状态、来源差异、审核状态和引用定位。交付截图、预览地址与已知边界；本人确认的是设计方向及流程，不自动批准任何资料或模型输出。

正式接入后的验收另列：真实任务/错误/取消与恢复、评分版本CAS及失效、付费同意、索引撤回与引用有效性、Obsidian往返、危险动作保护以及回归测试。不得用样稿交互冒充完成。
