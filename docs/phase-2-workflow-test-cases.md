# Phase 2 持久任务、导入与审核测试用例

日期：2026-11-04；编码前定义。对应 PRD v0.9。本轮为 Phase 2A 后端闭环，不声明整个 Phase 2 或 Phase 3 通过。

| 编号 | 操作 | 验收结果 |
|---|---|---|
| P201 | 导入真实 HTML/MP4，关闭重开数据库 | 原件字节与SHA不变；稳定来源ID和排队任务可恢复；未审核没有正式资格 |
| P202 | 相同内容重复/并发导入 | 只有一个来源、一个初始任务；重复返回原ID，不重复收费或处理 |
| P203 | 空文件、超限、伪扩展名、目录/符号链接、无授权确认 | 明确拒绝，不留下来源或队列记录，不执行原HTML脚本 |
| P204 | 磁盘低于配置保护线、复制失败、DB失败 | 不接受新素材；文件先原子落盘再登记；未登记孤儿不作为知识；只清理本次暂存 |
| P205 | 两连接同时领取任务 | 全局最多一个running；租约与随机令牌防旧worker完成/心跳覆盖 |
| P206 | 重启/租约过期 | 未开始外部调用可重排；已标外部提交但结果未知进入needs_attention，不自动重复POST |
| P207 | 远端task_id及阶段持久化 | 重开仍可查看；人工恢复仅远端查询路线可扩展，本轮不提供会重复提交的自动重试 |
| P208 | 失败重试、取消、过期worker迟到 | 显式重试留痕；取消后旧令牌不能发布；达到尝试上限不得再领取 |
| P209 | HTML worker转换 | 提取真实正文/表格，保留原HTML；不执行脚本、不取外链；动态/图像等缺失显式警告 |
| P210 | 视频已有真实产物接入 | 来源SHA匹配，保留转录/视觉/正文/摘要/笔记及方案身份；无匹配或伪造/模拟产物不冒称完成 |
| P211 | 完成结果和任务事务 | 结果版本、当前版本指针、任务成功原子提交；空输出/无证据不能完成 |
| P212 | 审核边界 | approve且有限分数≥配置目标才有资格；低分approve拒绝；NaN/bool/越界/空审核人拒绝 |
| P213 | 审核版本冲突/重复反馈 | 绑定当前version_id和内容SHA；旧版本/错SHA拒绝；相同review_id幂等、不同内容冲突 |
| P214 | 最新决定与人工修订 | reject/rework即时撤销；修订保留原机器版本，生成新版本且必须重新审核；旧评分不迁移 |
| P215 | 删除与重导入 | 软删除即时失去正式资格、取消未完成任务；不误删原输入/其他来源；同字节重导入不得悄悄复活 |
| P216 | 路径与日志安全 | 原文件名不参与路径拼接；输出路径限制在数据目录；CLI只输出安全错误/元数据，不读取.env或联网 |
| P217 | 端到端CLI | 新临时数据目录导入→处理/接入真实结果→查看→人工评分命令→资格查询→修订/撤回；合成审核只算功能测试 |

所有自动审核分数只在隔离测试数据使用，不代表本人授权审核现有真实素材。真实demo冒烟停在待审核，不替用户批准。

## 本轮结果

P201–P217在本地领域/导入/CLI范围验收通过。新增31项用例通过；完整158项回归中156通过、2项既有POSIX用例平台跳过，符号链接检查按环境可创建条件执行。真实3视频+2HTML五任务成功且新版本均待审核，未新增模型调用。逐项证据及限制见[验证记录](verification-results.md)，操作见[使用说明](phase-2-workflow-guide.md)。正式Web、云端视频自动编排、真实OSS和正式RAG索引不在本轮通过范围。
