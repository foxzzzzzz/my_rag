# 正式UI与已确认样稿一致性修正

2026-11-06。本人指出正式界面与第二版样稿风格不一致，本项重新打开3U-C视觉验收；原功能回归证据保留，不能替代设计还原验收。Phase 4不启动。

## 差异与修正方向

用户两张图分别为样稿问答和正式资料库，页面、宽度不同，不能只凭两图做像素比较；但正式代码已确认存在独立偏差：全局界面字号16px而样稿14px、品牌缺少“知”标识和导航图标、筛选标签水平堆叠而样稿上置、列表日期挤入正文、审核框及问答输入区新增样稿没有的完整外框、主区间距不同。

以已批准的design/ui-prototype-v2为基线还原，保留正式额外导航/权限/付费及真实空状态。禁止复制演示问题、主题或答案充填正式库。字体显式配置、图标用本地SVG、颜色/字号/间距集中tokens；正式功能状态机和API不变。

## 结果

**修正、正式发布及限定场景的独立复核已完成；等待本人确认实际视觉效果，Phase 4未启动。** 原因是正式接入只复用了部分颜色/布局概念，重新定义了界面字号、控件和结构；此前验收偏重功能、移动不溢出与数据保护，没有用同页同尺寸样稿对照拦住样式漂移。不是新增skill就能自动解决的问题，本轮已把对照要求补入项目skill和检查清单。

### 保留差异及限制

正式版有导入/任务/分类、批量选择、真实审核表单和明确付费同意；样稿仅两项导航、部分审核为只读记录、范围固定及预设回答，因此这些内容不机械复制。真实资料尚未设置主题，侧栏只显示“全部主题”，不会补上演示分类。

独立评审剩余两项P2：详情“返回资料库”仍是次级框线按钮，样稿是文本入口；审核状态未采用样稿绿/棕色强调。列入Todo后按本人反馈统一，本次不宣称逐像素还原。当前未在新样式下再次调用真实模型或生成新答案，回答正文语义/准确率不属本轮新增验收。
