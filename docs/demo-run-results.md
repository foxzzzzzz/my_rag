## 链路与限制

- ASR：百炼北京`paraformer-v2`，完整音频经REST临时上传及异步转写。处理音频分别20.480、414.912、640.801秒；原生最后一句结束于20.35、414.85、640.72秒，已核对音频长度与尾部时间。时间覆盖不证明文字无误。
- 视觉：百炼北京`qwen3-vl-plus`。V01密集时间采样；V02/V03结合全时段采样与场景变化补帧。**59帧是抽样，不能保证快闪文字或所有操作步骤均覆盖。** 请重点检查图表关系、数字术语及视觉独有信息。
- 文本：DeepSeek`deepseek-flash`，关闭思考模式；融合转录/画面证据，或基于HTML提取生成摘要和Markdown笔记。模型生成的解释仍需与原材料核对。
- HTML：不运行原文件脚本。表格/代码和原SVG保留，SVG结构作为文本上下文送文本模型；本轮没有将SVG渲染图另送视觉模型。原图对照为本地查看用途。依赖运行JavaScript才能生成内容的HTML仍缺样本，未验证该类型。
- 长HTML输出：H01第一次返回未通过非空/完整输出检查，原请求保留失败记录及未知费用上界；仅该项受控重试，输出版本升至2。H01重试和H02提高输出上限并增加篇幅约束，均返回完整JSON。篇幅提示属于软约束，实际笔记仍较长，页面可折叠和滚动查看。
- 本次是单套基线真实实测，尚未比较第二套ASR/视觉组合；按本人反馈再决定是否增加对照，不自动重复付费。
