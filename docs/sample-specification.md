# 首批样本与评审规范

版本v0.2；2026-11-03；依据 [PRD](PRD.md)。现有 `sources/douyin/` 下3视频、`sources/html/` 下2HTML直接作为demo，不要求先制作gold、参考转录或逐事实标注，不强制50视频/500事实或30/20划分。

## 准备内容

保留有权处理的原文件及附件，用稳定来源ID、相对路径和SHA256识别；清单由工具整理，不要求本人手填复杂JSON。原材料、真实输出与反馈保存在被Git忽略的本地目录。

每份展示来源、run_id、方案版本、不可变输出版本、转录/画面证据、摘要、来源笔记、耗时及费用；未知明确标记。没有真实结果时只显示待处理，不能用模拟或占位结果申请批准。视频证据带时间；HTML保留标题、代码、表格、SVG和定位信息，不执行脚本或自动联网。

## 本人评分和决定

对照原材料与输出，给整体0–100分及approve/rework/reject，备注/问题标签可选。默认≥98分且明确approve才满足审核条件；分数是个人整体评价，不是准确率或覆盖率统计。高分不自动入库，低分不因批准而通过；预研工具只汇总审核就绪，不实际写RAG。

评分绑定来源哈希、run_id、方案和输出版本。机器原输出、人工修订分别保留和评分，内容变更重新评；同版本最新明确决定生效，返工/拒绝撤销旧批准，历史保留。

当前协议见 [个人评审协议](personal-review-contract.md)，准备见 [样本清单](sample-preparation-checklist.md)。[旧协议](tool-contract.md) 仅是可选annotated_benchmark，其gold、样本数及formal_pass不是当前personal_review审批。
