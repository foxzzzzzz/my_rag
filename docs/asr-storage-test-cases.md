# ASR双存储模式实施前用例

日期：2026-11-04；依据PRD v0.8，默认temporary，managed_oss仅手动配置启用。本轮不发模型请求、不创建Bucket、不读取或改写真实.env。

| 编号 | 用例 | 预期 |
|---|---|---|
| O01 | 默认临时模式、正式OSS未配置 | 使用既有百炼Key引用，正式SDK/凭证不成为依赖 |
| O02 | 模式名错误/手动选择正式模式缺配置 | 配置失败且零网络操作，不自动回退 |
| O03 | 临时上传政策及表单 | 指定同一ASR模型；上传不携带百炼Bearer，返回oss://URL与解析请求头 |
| O04 | 正式私有OSS | 真实实现SDK上传/签名GET/专用对象清理；通过fake Bucket离线验证调用契约 |
| O05 | 统一文件引用与日志 | 保存backend、输入哈希/大小/模型/有效期；repr/元数据不泄露密钥或完整URL |
| O06 | 超限/不存在输入、非HTTPS或非授权主机 | 发起上传前拒绝；参数外置，无静默截断 |
| O07 | 切换/清理 | 旧引用保留原backend，错配适配器拒绝；只能清理本前缀、本适配器创建的对象，临时模式不假称主动删除成功 |
| O08 | 过期/上传失败/SDK缺失 | 明确错误、无自动跨模式或模型切换；异常文本脱敏 |
| O09 | 配置/政策字段为null、数组或错误类型 | 返回统一安全错误，不逸出原始AttributeError、不上传或回退 |
| O10 | 正式上传已被接受但客户端超时 | 只尝试清理本次生成key，不签名、不切换；清理未确认时保留归属记录并明确失败 |
| O11 | SDK初始化失败 | 不尝试删除任何对象，返回安全错误 |

官方接口已验证与新适配器代码回归分开记录。正式OSS离线测试通过不代表Bucket权限、签名下载、真实服务可达或付费联调通过；手动切换前再做A01–A06。

## 临时存储配置边界补充用例

- 非字典配置、空或非字典 temporary、非法 API HTTPS 地址或主机白名单、非法上传后缀应在创建时返回 StorageError。
- 空白模型、畸形政策字段和非字符串上传目录应返回 StorageError，不切换后端。
- 临时引用有效期必须是正整数且不超过 48 小时；响应大小上限从配置读取。
