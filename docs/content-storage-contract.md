# 长期内容与 HTML 接入契约

日期：2026-11-05；对应 PRD v0.12。实现验收见 phase-2-content-validation.md。

## 数据职责

Markdown 和永久附件是长期可读的知识内容，不能仅在点击下载时生成。SQLite 保留不可变结构化版本、当前指针、任务与审核历史，并驱动可重放的文件同步。索引仅为派生数据。文件不能自报批准而获得检索资格，最终授权仍核对 SQLite 当前版本与最新审核。Phase 3还须强制启用内容存储并校验同步，不能将旧纯数据库兼容模式的审核查询单独当索引授权。

稳定 note_id 使用 source_id；内容版本使用既有 version_id。每版本保存 Markdown、结构化证据及校验信息；另有当前入口标明待审/批准/撤回/删除状态。审核状态变更不改写原机器内容。导出共用同一渲染协议，结构化私有路径、密钥字段、签名 URL 和任务租约不进入笔记元数据；自由正文保留原文，不用正则删除技术路径、普通链接或代码示例。

文件系统与 SQLite 不存在跨介质原子事务：采用持久待同步记录、受控暂存与原子替换、校验与幂等重放。未同步/损坏时明确失败，后续正式 RAG 必须同时检查审核资格及内容同步/校验。不能仅因审核为 approve 就把损坏或未同步内容加入索引。

永久关键帧按来源/内容哈希与版本证据关联，读取校验 SHA；临时 video-work 不能成为唯一证据地址。旧数据补建显式执行，不自动清理原缓存。原视频 7 天保留及全局备份仍属后续验收；本轮不删除原片。

默认真实开发数据与 reports 下演示目录隔离。Markdown/附件可独立阅读和供后续重建内容索引；完整任务、审核、版本关系恢复仍需数据库备份。手工修改服务器持久目录不自动获得信任，Obsidian 编辑重传须通过后续冲突及重新审核流程。

## HTML 模式

保留原 HTML，静态解析正文、表格、代码、可识别 SVG/公式结构作为证据，禁止执行任意脚本或请求外链。JS 图、远程图片、无法提取的公式明确提示补充静态导出，不假称已视觉识别。

离线预览保留且明确标识；已验证模型整理作为显式付费操作，沿用 DeepSeek 文本能力、结构化摘要/笔记提示及统一研究预算账本。网页配置开关和用户同意共同控制付费，不因普通导入自动触发。同步 POST 未知结果禁止自动重发，已完成阶段持久缓存；新内容版本无旧评分。后续所有正常 HTML 模型处理仍由本人复核。

## 本轮边界
