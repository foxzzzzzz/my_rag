# 前端视觉统一与交互回归

视觉基线为已确认的资料库离线样稿。生产前端正常入口仍为现有 Web 服务。本轮验收在隔离构建和模拟响应中执行，实际业务数据与模型费用由既有集成用例覆盖。

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| VC01 | 在 1440、861、768、390px 打开资料库并与同视口样稿对照。打开类型、审核、标签，沿 Tab 顺序访问各控件。 | 导航与工具栏对齐，标题和分类列随可用宽度重排。展开内容在资料列表上方，控件和焦点可见。资料库的网页、视频、图文标识为透明底，图标和文字分别同为蓝、橙、青绿色，尺寸沿用原样。详情和任务页仍使用实色底。 |
| VC02 | 搜索或筛选、清空，双向排序。逐行勾选、全选、批量分类并返回详情。模拟空结果和读取失败。 | 使用原筛选及排序规则，批量提交保留修订号，返回保留滚动和筛选，空结果可恢复。 |
| VC03 | 同一资料在宽屏和手机打开详情。切换阅读内容和证据，保存评分草稿。以 97 分、98 分检查批准门槛。 | 详情、阅读区和审核区使用统一字号及边界。草稿保存不发审核请求，达到门槛并明确提交才审核。 |
| VC04 | 进入问答，切换自定义范围和本地检索，检查资料选择与费用按钮。使用已有问答接口用例核对返回引用及失效。 | 显示范围、费用及证据内容，保持既有授权、检索和引用行为。 |
| VC05 | 在导入确认权限之前和之后选文件，展开抖音链接、收藏及 Obsidian。进入任务，切换未归档/已归档、筛选与排序。 | 导入权限及任务动作保持原入口和顺序。任务滚动时表头固定，详情和操作可读。 |
| VC06 | 搜索主题或标签，分别打开桌面编辑抽屉、手机编辑弹窗，取消或 Esc。打开回收站，检查到期及可恢复资料，提交一次隔离恢复。 | 分类类型、回焦、编辑顺序和恢复请求保持原语义。各表面、标签、输入框、按钮与导航使用共同样式。 |
| VC07 | 打开连接失败、登录和初次加载状态。检查 390px 下无横向溢出，Tab 焦点和对话框可达。 | 原提示、登录和重试入口正常，窄屏操作不被布局裁切。 |
| VC08 | 在 1440px 和 390px 打开视频资料的人工修订，用长内容检查五个字段，放弃草稿后再编辑并保存新版本。 | 每个字段默认可见高度至少 450px，文字使用 16px 并支持上下滚动及纵向调整。放弃后恢复原内容，保存时携带当前版本 ID 和全部字段。审核意见保持原高度。 |

### 验收环境

- 用 Vite 构建正式入口，在本地 Edge 使用模拟 API 屏蔽真实写入和收费请求。
- 对照浏览器截图及计算样式，确认同页同视口的字体、对齐、实际展开状态与数据可读性。
- 运行前端单测和后端接口回归。业务验证以测试请求和响应为准。

在项目根目录运行以下命令。前端依赖、Python Playwright 和 Edge 需可用。

```powershell
node web/node_modules/vite/bin/vite.js build web --outDir ../tmp/ui-unification/current
python tools/check_ui_consistency.py tmp/ui-unification/current --screenshots tmp/ui-unification/screenshots
npm --prefix web test
```

浏览器用例可通过 `--baseline` 指向改动前的 Vite 构建，使用同一组资料和对应状态生成对照截图。浏览器用例验证 1440、861、768、390px，另用 1280×480 验证资料库滚动、返回和吸顶焦点；后端回归沿用 API、Web 服务、分类、RAG、抖音和 Obsidian 测试。

### 2026-11-19 本机验收

- Edge 浏览器通过 VC01–VC07。资料库与确认样稿对照的导航、标题、搜索、筛选及列表起点对齐，字体和色值一致。正式页面省略「离线演示」标识。
- 前端 Node 单测 75 项通过；指定的六个后端测试文件共 116 项通过。Starlette TestClient 报告一条依赖弃用警告。
- 改前、改后使用同一组隔离 API 响应。问答付费同意与调用、审核提交、文件导入和回收站恢复均有模拟请求校验。
