2026-11-06，编码前发布。用户反馈第一版“AI味道太重”，尚未批准设计；本轮替换视觉方向，保留三页功能语义。

| 编号 | 操作/检查 | 验收预期 |
|---|---|---|
| V201 | 与第一版对照查看三页首屏 | 无英文眉题、标语、超大宣传标题、衬线展示字体；中性笔记工具界面，结构/密度改变，不只是换色 |
| V202 | 在资料库搜索、按来源/审核/主题过滤，清空 | 数据结果一致，选中状态可辨；无结果可恢复；全部演示数据仍明确标识 |
| V203 | 阅读视频/HTML详情，切换证据、导航往返 | 正文有自然段/列表/表格，来源专属入口正确；正文和审核区层级清楚；键盘焦点保留 |
| V204 | 待审输入97/98分及意见；修改未保存；批准 | 97不可批准、98存档后单独批准；改分/意见未保存不可批准；切证据/导航不丢草稿，批准记录保留意见 |
| V205 | 问答空输入、预置回答、拒答、①与证据 | 提问入口首屏可见；回答文章化，引用归属正确；预置/范围/付费边界诚实；非预置输入不冒充真实回答 |

| V207 | 检查独立预览及原服务 | 同源外部JS/CSS符合CSP；无模型/业务API/真实草稿写入；第一版、正式入口及已有评分页保持可访问 |
