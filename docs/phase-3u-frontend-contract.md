# Phase 3U-C：正式前端接入约定

依据[已确认第二版](ui-redesign-v2-brief.md)及[UC01–UC19](phase-3u-frontend-test-cases.md)。现有业务API、数据模型、索引和模型配置保持；本轮改React呈现和必要的客户端交互状态。2026-11-06正式发布完成，见[工程验收](phase-3u-frontend-validation.md)。

## 页面与职责

- 应用壳/资料库/详情由主前端模块负责：浅灰侧栏、白色工作区、蓝色操作强调；资料库用主画布列表，详情为独立阅读/审核视图，避免两页同时挤在一屏。
- 保留导入/任务/分类及批量管理、Obsidian、AI建议等能力，次级操作折叠呈现。侧栏主题使用真实catalog ID联动资料库。所有页面使用同一tokens与基本控件。
- 问答组件独立负责真实状态/范围/事件流/引用：输入在首屏，范围和检索设置折叠，索引维护单独折叠，不隐藏费用同意。与主壳通过既有api/session/sources/catalog对接。
- 样式主文件与外部tokens统一管理。问答使用`.rag-*`、阅读/审核使用`.source-*`/`.review-*`，共用`.page-heading`/`.toolbar`/`.muted`/`.primary`/`.danger`/`.error`。既有citation样式按新tokens覆盖，证据渲染逻辑不改写。

## 评分与版本

“保存评分草稿”只保存在当前打开页面的内存，明确说明刷新会丢失；不新增draft API，不写浏览器持久存储，不把保存当批准。草稿键包含source_id/current_version_id，含评分、审核人、意见、决定和保存快照；任一字段变更后需重新保存，正式提交仍复用既有version_id/content_sha256/review_id协议。

高分不自动批准，批准门槛从session.config.quality_target读取。返工/拒绝按既有规则允许低分并即时撤销资格。当前正式审核在旁显示，重新审核不继承批准到新版本。保留人工修订草稿的来源/版本绑定及显式放弃/刷新路径，阻止后台轮询改绑。刷新/取消/删除均需说明影响，不自动重发未知结果请求。

## 安全与验证

文章可用React节点安全解析常见Markdown结构，不执行原始HTML；不使用dangerouslySetInnerHTML，不内联运行上传脚本，不自动加载外站资源。复杂内容可保留原文查看/下载兜底，证据不得编造时间或DOM定位。问答继续沿现有分段/脚注及校验后事件流。

不新增真实模型调用用于UI测试。隔离合成库处理文件、审核、修订、删除/冲突；如需模拟问答事件须标明合成，不把它写入真实资料或评分页。真实8765只读核验原资料/审核与索引，构建产物发布保留所有已有assets，用户已有评分草稿不可清理。

本地审核请求开始与结束均更新问答审核epoch，撤下旧结果并在提交期间禁止新问答/检索/建索引；版本号未变化或未知提交响应也不能保留旧证据。返回问答时重新校验引用，跨客户端审核暂无实时推送。
